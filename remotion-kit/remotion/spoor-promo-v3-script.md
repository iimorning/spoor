# 雪泥 Spoor — 推广视频 V3 分镜脚本（定稿）

> **核心故事：**  
> 一个问题先被写下来 → 照片和笔记停在房间外面 → 拖进阿狸的房间，成为这一轮的上下文 → 按住说话，在右侧对话里问、搜、看图 → **只有拖出去的，才变成画布上的材料** → 框选 → 合成一篇还能回到来源的长文。
>
> **核心表达：**  
> **聊天是过程，画布是你决定留下的。**

**时长：** 75s · 1920×1080 · 30fps  
**实现：** `SpoorPromoV3.jsx` · `spoor-promo-copy.js`（`zh-v3` / `en-v3`）· `spoor-promo-v3-zh.json`  
**渲染：** `npm run remotion:render:spoor-v3-zh`  
**只出现阿狸。字幕即配音稿。**

已锁定：开场先打出问题；保留按住说话；总长 75 秒。

---

## 0. 开场｜0:00–0:06

米白画布。中央逐字打出：

> **为什么有些地方，我们永远不会忘记？**

Logo「Spoor」晚一点淡入左上。问题落成房间里的问句卡。

**配音：** 有时候，你只是突然想到一个问题。

---

## 1. 这是房间｜0:06–0:13

虚线房间出现，标签「阿狸的房间」。问卡 + 问题卡在里面。房间右侧外面淡入：照片、笔记、主题卡「记忆与空间」。

**配音：** 不用急着整理。先把这一刻想到的，都放在一起。

---

## 2. 拖进来｜0:13–0:22

光标把照片、笔记拖进房间。主题卡留在外面。点问卡后，准备按住底部麦克风。

**配音：** 把照片、笔记拖进去。阿狸就能看见你正在看的东西。

---

## 3. 在对话里问，也在对话里找｜0:22–0:38

按住麦克风说话。右侧对话滑开。

用户：帮我看看这是什么。为什么我到现在还记得它。  
阿狸：也许你真正记住的，不是那栋房子，而是那里曾经发生过的生活。  
用户：那帮我找一点关于地点和记忆的资料。

百科摘录、老街图出现在**线程里**，带拖动手柄。不自动铺上画布。

**配音：** 想到什么，就先聊什么。百科、文章、图片，会先出现在对话里。聊天是过程，还不是结论。

---

## 4. 想留下的，才回到画布｜0:38–0:50

从侧栏拖出：阿狸那句关键回复、百科、图片，落成画布卡片并连线。主题卡仍在外面，稍后淡化。

**配音：** 真正想留住的，再拖回画布。不是每个回答，都值得留下。

---

## 5. 框选，写成一篇还连着来源的长文｜0:50–1:07

短拉远看结构 → 框选核心卡 → 「合成文章」→ 大纲 → 长文编辑器，引用连回来源。

**配音：** 留下来的，才慢慢变成你的材料。框选真正重要的几张。让 AI 帮你收成一篇文章。

---

## 6. 收尾｜1:07–1:15

长文停住。Logo：中文「雪泥」，英文「Spoor」。最后一句：**从一个想法，到一篇长文**。spoor.ink

---

**动线：** 问题 → 房间外材料 → 拖进房间 → 语音 + 侧栏搜索 → 拖出留下的 → 框选 → 长文 → 回到来源
