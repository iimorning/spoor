# 雪泥宣传视频 · 导演规范（V3 定稿沉淀）

> 本文档沉淀 V2/V3 迭代过程中确认的所有审美与叙事决策，下次做视频（或大改）时先读这里。
> 对应实现：`SpoorPromoV2.jsx` / `spoor-promo-copy.js` / `spoor-promo-v2-zh.json`。

---

## 一、叙事原则

1. **讲一次真实的使用过程，不要罗列功能。**
   主线永远是：我突然想到一个问题 → 说出来 → 阿狸帮我去网上找 → 东西越来越多 → 我挑选、连接、讨论 → AI 帮我组织 → 形成一篇真正属于我的文章 → 文章观点可回溯到画布。
2. **只出现阿狸（问卡），不要其他 agent / 角色出现。** 多人格、角色工坊等都不进视频。
3. **必须体现多模态输入**：不只是文字——联网百科、图像、视频、用户自己的照片/笔记/语音都要出现。
4. **散乱想法的归宿是「汇集成长文」**。结尾落在**长文编辑器页面**（真实感），不要星图、烟花这类抽象炫技收尾；也不要单独做「保存观点 / 知识存档」段落。
5. 全片最后一拍只讲一句：**「从一个想法，到一篇长文」**；域名用 **spoor.ink**（不要旧的 netlify 二级域名）。

## 二、镜头语言（视觉焦点）

1. **内容出现在哪，镜头就推到哪。** 任何新卡片出现时，推近到 1.3–1.9 倍，保证 1080p 下卡片上的文字清晰可读。禁止一直全屏俯拍。
2. **镜头只允许两种运动**：
   - 水平平移（同一内容带内逐个看过去）；
   - 明确的垂直换章（进入下一个叙事阶段）。
   **禁止对角线大跳**——上一拍在下方讨论、下一拍跳到顶部素材，观众会晕。
3. **拉远全景只用于「结构时刻」**，全片两次足够：
   - 材料铺完后（「整个画布丰富起来」）；
   - 筛选/淡化时（「看结构、做取舍」）。
   拉远后必须再推回特写，形成呼吸感。
4. 两次全景之间的所有内容，都用特写逐个呈现。

## 三、空间布局（动线）

画布上的卡片位置必须服从**单向阅读动线**，像读书一样不回头：

```
问题卡 + 关键词（顶部）
   ↓ 垂直换章
阿狸问卡 + 对话（正下方）──→ 百科 → 图片 → 视频 → 论文（同一水平带，纯右移）
                                                        ↓
讨论卡（回到左侧）←──────── 语音 ← 笔记 ← 照片（下一行折返向左）
   ↓
观点卡（讨论下方）──→ 大纲卡（右侧）──→ 推近进入长文编辑器
```

- 相关材料放在**同一水平带**，镜头才能纯平移。
- 换行时折返（右→左），像文字排版换行，不要斜穿画布。
- 实现上布局集中在 `POS` 常量、镜头集中在 `CAM` 关键帧数组，改布局=改这两张表。

## 四、节奏

1. **每一拍要留够看清内容的时间**（特写至少 ~2 秒），宁可总长变长（现定稿 74s），不要连切。
2. 用全局调速系数统一控制节奏，不要手改几十个时间点：

```javascript
const WORLD_T0 = 4.8;   // 开场之后才拉伸
const PACE = 1.3;       // 觉得快就调大这一个数
const pace = (t) => WORLD_T0 + (t - WORLD_T0) * PACE;
```

   `TL`（时间线）、`CAM.t`（相机关键帧）、文案里对话气泡的 `at` 都经过 `pace()`。
3. 调速后记得同步：字幕 JSON 的 `timestampSegments`、文案里的场景分界、`SpoorPromoV2Duration`。

## 五、界面与可读性

1. **所有屏幕组件和字体都要放大**——观众是在看视频不是用产品，按「1080p 视频里能轻松读」的标准设计，不是按真实 UI 密度。
2. **连线用项目真实样式**：直线、 muted 灰 `#d1cfca`、2px、画在卡片**下层**；用 `strokeDasharray/offset` 做生长动画。不要红色贝塞尔曲线横穿卡片。
3. **不要左上角章节标题卡**——底部已有字幕胶囊，后期还有配音，信息只保留一处。
4. 底部字幕胶囊时间轴必须和画面节奏同步（调速后重排）。
5. 界面 chrome（品牌、侧栏、工具栏、缩放条）作为环境元素常驻即可，不与叙事抢戏。
6. **拟真光标微动效**——只有平移缩放会有 PPT 感；用光标动作增加「可用感/实体感」：
   - **拖拽连线**：光标从一张卡拖出连线到另一张卡（线随光标生长）；
   - **框选**：marquee 虚线框随光标拖大，完成后选择圈接管；
   - **拖拽归位**：新卡片先落在偏移处，光标抓住拖到最终位置；
   - **逐字输入**：用户自己的笔记打字机逐字出现（带闪烁光标）；
   - **按住说话**：按住 mic 按钮是 press-and-hold（光标压下），不是单击。
   实现要点：光标位置用「世界坐标 × 当前相机」换算（`toScreen`），相机移动时拖拽依然粘在卡片上；按下态用 `pressed` 让光标微缩。

## 六、明确不要的东西（已否决）

- ❌ 多 agent / 角色工坊 / 星图（Cosmos）等抽象收尾
- ❌ 「知识存档 / 观点卡 / 保存观点」段落：讨论收束后直接进大纲与长文；不要观点卡、不要保存按钮、不要飞入侧栏、不要 toast
- ❌ 红色贝塞尔连线
- ❌ 章节标题卡（左上角毛玻璃标题）
- ❌ 全程固定全屏机位
- ❌ 功能点罗列式叙事
